\section*{Data and Code Availability}\label{sec:availability}

The NORS public dataset is available from the CDC open data portal~\cite{cdc2024norsdata}. The dated extract (\texttt{nors\_soda\_full\_20261125T040830Z.csv}, SHA-256 pinned), derived cohorts, excluded-outbreak audit summaries, analysis results JSON, all 14 CSV/LaTeX tables, and replication scripts are openly archived at \url{https://github.com/wangchi2068/nors-hosp-ranking-partial-id}. Rerunning the pipeline from the raw extract reproduces all deterministic bounds, cohorts and formatted CSV tables identically and reproduces all Monte Carlo and root-finding quantities to within cross-platform numerical tolerance ($\le 10^{-5}$).

\section*{Ethics}\label{sec:ethics}

The analysis used only publicly released outbreak-level counts; no individual-level or identifiable data were accessed.
