\section*{Data and Code Availability}\label{sec:availability}

The NORS public dataset is available from the CDC open data portal~\cite{cdc2024norsdata}. The dated extract (\path{nors_soda_full_20261125T040830Z.csv}, SHA-256 pinned, retaining NORS row \texttt{:id} keys for future CDC revision checks), Socrata view metadata, derived cohorts, excluded-outbreak audit summaries, analysis results JSON, all 18 CSV/LaTeX tables, and replication scripts are archived with this release. Rerunning \texttt{reproduce.py} from the raw extract reproduces all deterministic bounds, cohorts, and formatted non-bootstrap CSV tables identically, matches 2,000-replicate bootstrap distributions within Monte Carlo tolerance, verifies identical 30-hypothesis rejection decisions across worst-case, $\delta=5\text{ pp}$, and $\delta=0$ specifications, checks headline manuscript numeric alignment (\texttt{verify\_text\_numbers.py}), and reproduces numerical simulation quantities to within deterministic ($\le 10^{-9}$) or cross-platform BLAS ($\le 10^{-3}$; at most $\approx 0.025$ in rare Gaussian-tail quantiles) tolerance without altering any published table entry.

\section*{Ethics}\label{sec:ethics}

The analysis used only publicly released outbreak-level counts; no individual-level or identifiable data were accessed.
