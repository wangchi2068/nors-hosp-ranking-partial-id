\section*{Data and Code Availability}\label{sec:availability}

The NORS public dataset is available from the CDC open data portal~\cite{cdc2024norsdata}. The dated extract of the dataset, the analysis results file from which every reported number is taken, the record-audit and selection summaries, the analysis programs that recompute the results file from the extract (including the seeded outbreak-level bootstrap), and the program that generates every table and figure are distributed with this article. Rerunning the pipeline from the dated extract reproduces every reported number, table and figure exactly.

\section*{Ethics}\label{sec:ethics}

The analysis used only publicly released outbreak-level counts; no individual-level or identifiable data were accessed.
